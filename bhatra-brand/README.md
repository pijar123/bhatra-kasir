# bhatra-brand

Salinan dokumen brand & konten Warung Jajan BHATRA. Sumber kerja utama ada di Mac `~/MABES/bhatra/` (gambar, video, KV).

- `AI.md`: panduan untuk AI (baca dulu)
- `catatan.md`: status & tugas (sama dengan `CATATAN.md` di akar repo)
- `strategi-konten.md`: rumus konten Reels, bahasa kamera, caption, evaluasi
- `konten/YYYY-MM-mingguN/`: script mingguan + cover
- `skrip/`: pembuat logo/maskot/KV/ikon (rig Little Bhre) dan `reel1b/` kerangka video kartun (set ep.js TK + rig Little Bhre)

Video mp4 tidak disimpan di repo (ada di Mac `konten-harian/`).
